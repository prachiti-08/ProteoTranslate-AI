# 🧬 ProteoTranslate-AI

AI-powered bioinformatics platform for DNA analysis, mutation detection, protein translation, biological interpretation, and research assistance.

## Overview

ProteoTranslate-AI is a bioinformatics platform designed to bridge the gap between raw genomic data and biological understanding. The system enables users to analyze DNA sequences, detect mutations, translate genetic information into proteins, and generate meaningful biological insights.

The project aims to make genomic analysis accessible for students, researchers, and healthcare professionals through an interactive web-based platform.

## Features

### Phase 1: DNA Analysis Module ✅

- DNA Sequence Validation
- DNA → mRNA Transcription
- Codon-Based Protein Translation
- Start Codon Detection
- Stop Codon Detection
- Sequence Statistics
- Amino Acid Identification
- Automated Analysis Report Generation

### Phase 2: Mutation Analysis Module ✅

- Original vs Mutated Sequence Comparison
- Point Mutation Detection
- Mutation Position Identification
- Mutation Statistics
- Comparative Analysis Dashboard

### Phase 3: GenAI Biological Explanation Module 🚧

- AI-generated Biological Interpretation
- Protein Function Explanation
- Mutation Impact Description
- Educational Insights
- Research-Oriented Explanations

### Phase 4: Research Assistant Module 🚧

- Literature Support
- Research Summaries
- Genomics Knowledge Assistance
- Biomedical Information Retrieval

## Installation

### Clone Repository

```bash
git clone https://github.com/prachiti-08/ProteoTranslate-AI.git
```

### Navigate to Project Directory

```bash
cd ProteoTranslate-AI
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```
